CardPilot Strategy MVP v2

A local-first prototype for testing credit-card application sequencing.

HOW TO TEST
1. Unzip CardPilot_Test_Build.zip.
2. Open cardpilot/index.html in a browser, or serve the folder with any static web server.
3. On iPhone, deploy the folder to a static host (Netlify/Vercel/GitHub Pages), open the URL in Safari, then Share > Add to Home Screen.

WHAT WORKS
- My Cards + automatic rolling 5/24 count
- Active SUB progress and deadline tracking
- Upcoming expense entry and SUB matching
- Benefits/certificate expiration tracking
- Apply Next strategy with Wait / Candidate / Save / Avoid states
- Strategy Timeline for future plans such as Southwest Companion Pass
- Offer watch thresholds
- Personal strategy settings
- Export/import of your data as JSON
- Local browser persistence

IMPORTANT
Offer data in this test build is sample/manual data, not a live verified feed. Do not make an application decision from the sample offer amounts without verifying the issuer's current terms.
